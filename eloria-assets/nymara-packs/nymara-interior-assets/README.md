# Nymara interior asset pack

70 native E3D modules across 11 reusable interior kits, with PNG textures and editable OBJ/MTL sources. Copy `runtime/` over the generated Eloria data directory. Use `nymara_interiors.json` for stable paths and kit membership. Modules cover the seven approved landmark dungeons as reusable construction pieces; finished ELM room layouts remain map-authoring work.
