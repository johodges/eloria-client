# Manymouth Delta production map

This starter package converts the supplied `manymouth_delta.elm` terrain, routes, water mask, and landmark placements to Godot-native GLB. The ten-panel board in `references/00-concept-detail-board.png` is the visual authority for the next modeling pass.
