# Mirrorhold production map

A 576 m x 576 m Nymara region: an observatory citadel on a mountain summit,
crowned by a mirror-sphere in a brass armillary; a civic descent of terraces,
canals and switchback roads down its south face; and a glacier-fed lake in the
southern basin with a colonnaded ring at its centre on four causeways.

Everything in this package - every mesh, every texel - is generated by the code
in `source/` and the shared toolkit in `../_toolkit/`. Nothing is imported.

## Contents

| File | What it is |
| --- | --- |
| `world.glb` | Self-contained glTF 2.0. Geometry, materials and embedded textures. No extensions, no external files. |
| `world-lod2.glb` | Reduced package: far-tier vegetation only, no ground clutter, half-resolution textures. Not selected by the loader; it is there for low-end machines. |
| `world.json` | The runtime manifest: bounds, coordinate transform, spawns, collision, navigation, landmarks, interactives, markers, harvestables, portals, roads, water, environment, minimap transform, provenance. |
| `collision.bin` | 1152 x 1152 half-metre traversability grid, `EWCG-v1`. |
| `minimap.webp` | Rendered from the final geometry, not drawn. |
| `references/` | Concept art, captures and comparison sheets. |
| `source/` | The region: composition, placement passes, built kit, camera set, build script. |

## Building it

```sh
make -C ../_toolkit/native            # preview rasteriser; not needed for the package
cd source
python3 build_mirrorhold.py           # world.glb, world.json, collision.bin, minimap, LOD2
python3 ../../_toolkit/verify_runtime.py --package ..
python3 ../../_toolkit/validate_gltf.py ../world.glb
python3 ../../_toolkit/export_source_elm.py    # regenerates ../source-elm/mirrorhold.elm
python3 ../../_toolkit/capture_views.py        # offline preview captures
python3 ../../_toolkit/make_comparison.py      # concept-versus-build sheets
```

The build is deterministic: a cache-cold rebuild reproduces every artefact
byte-for-byte. Runtime startup never depends on rerunning any of it.

## Verification at the committed build

- `validate_gltf.py`: **0 errors, 0 warnings, 0 infos**
- `verify_runtime.py`: **0 errors**, 331,776 server tiles sampled,
  **0 grounding misses**, 3 warnings (cliff discontinuities, one
  collision/surface cell, and the armillary, which is meant to stand above its
  drum)
- 300,866 unique / 1,246,764 instanced triangles, 2,308 nodes, 16.1 MB.
  That is 3.8 instanced triangles per square metre, inside the repository's
  1.5 M visible-triangle desktop guideline; texture memory is 119 MiB
  uncompressed against a 512 MiB guideline.

## Server dependency

This package needs a 96 x 96 ELM server map with its arrival at tile
(174, 174). `../source-elm/mirrorhold.elm` is regenerated to match, and the
server-side change is on `feature/mirrorhold-576m-server-map` in
`eloria-server`. Without it the region loads against a 32 x 32 map and most of
the world is unreachable.
