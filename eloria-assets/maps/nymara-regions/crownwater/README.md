# Crownwater production map

This starter package converts the supplied `crownwater.elm` terrain, routes, water mask, and landmark placements to Godot-native GLB. The ten-panel board in `references/00-concept-detail-board.png` is the visual authority for the next modeling pass.

- Landmark instances: 65
- Texture kit: base color, tangent-space normal, and ORM
- Current status: terrain, traversal, material language, and landmark silhouettes; final hero geometry and set dressing remain in progress.
