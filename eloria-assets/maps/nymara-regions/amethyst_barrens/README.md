# Amethyst Barrens production map

This starter package converts the supplied `amethyst_barrens.elm` terrain, routes, water mask, and landmark placements to Godot-native GLB. The ten checkpoint subjects in `world.json` remain the visual-production brief. The invalid generated detail-board PNG was excluded and must be regenerated before visual review.
