# Amberwood authoring toolkit

Pure Python (numpy + Pillow) plus one small C rasteriser used only for offline
previews. Nothing here imports a model, a texture, or a third-party asset pack:
every mesh and every texel in the shipped package is generated by this code.

## Entry points

| Script | Purpose |
| --- | --- |
| `build_amberwood.py` | Builds the whole runtime package: `world.glb`, `world.json`, `collision.bin`, `minimap.webp`, the validator report and the performance summary. Deterministic for a given seed. |
| `verify_runtime.py` | Reproduces the client's grounding and navigation contract offline and writes `verification-report.json`. |
| `validate_gltf.py` | Standalone glTF 2.0 / GLB validator. |
| `capture_views.py` | Renders the comparison captures listed in `references/captures/index.json`. |
| `make_comparison.py` | Builds the concept-versus-build comparison sheets. |
| `preview.py` | Shared harness: caches the texture set and turns a `RegionBuild` into a renderable scene. |

```sh
make -C native            # build the preview rasteriser (not needed for the package)
python3 build_amberwood.py
python3 verify_runtime.py
python3 validate_gltf.py ../world.glb
```

## Modules

| Module | Contents |
| --- | --- |
| `amberwood/noise.py` | Seeded value/fBm/ridged/Worley noise, tileable variants, deterministic RNG. |
| `amberwood/mesh.py` | Triangle mesh container, transforms, welding, angle-weighted normals, tangents, and the modelling primitives (box, tapered cylinder, swept tube, lathe, extrude, loft, heightfield, icosphere, stairs, arch, gable roof). |
| `amberwood/textures.py` | Every procedural PBR material: bark, leaf-spray atlases, timber, carved wood, shingles, ashlar, rubble, cliff, cobble, forest floor, trail, shore, meadow, ash, iron, cloth, canvas, thatch, amber, amber glass, water. |
| `amberwood/materials.py` | The single material table shared by the GLB export and the preview renderer. |
| `amberwood/gltf.py` | Minimal spec-correct glTF 2.0 / GLB writer with embedded buffers and images. |
| `amberwood/terrain.py` | Heightfield sculpting operators, per-cell surface classes, crack-free multi-material export, water planes, distant backdrop. |
| `amberwood/trees.py` | Species profiles and the grown-skeleton tree generator, plus fallen logs and stumps. |
| `amberwood/architecture.py` | Timber-and-stone building kit and whole buildings. |
| `amberwood/stonework.py` | Arches, the monumental gate, masonry bridges, balustrades, fountains, statues, retaining walls, forest gates, channels, waterfalls, rotunda, and the multi-material `MeshGroup`. |
| `amberwood/treecraft.py` | Canopy platforms, suspension walkways, tree dwellings, spiral stairs, the hollow-tree hall. |
| `amberwood/props.py` | The lived-in economy: containers, carts, benches, market stalls, amber working, fishing, boats, docks, fences, signs, wells, braziers, and natural dressing. |
| `amberwood/region.py` | The authored region plan: extents, anchors, routes, watercourses, terrain sculpting. |
| `amberwood/populate.py` | Placement passes: forest, undergrowth, ground detail, settlement, landmarks, water. |
| `amberwood/render.py` | Offline preview renderer binding `native/libraster.so`. |
