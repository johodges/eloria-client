# Westhaven

A production Nymara region map: a working harbour city on a south-facing
headland, 576 m x 576 m at one metre per server tile.

Everything in this package is generated by `source/`. No model, texture or
third-party asset is imported; every mesh and every texel is produced by the
shared toolkit at `../_toolkit/` plus this region's own composition, kit and
material recipes.

## What is here

| File | What it is |
| --- | --- |
| `world.glb` | the runtime map: geometry, materials and textures, self-contained, no glTF extensions and no external files |
| `world-lod2.glb` | reduced package - far-tier vegetation only, no ground clutter, half-resolution textures |
| `world.json` | the world manifest, schema version 1 |
| `collision.bin` | 1152 x 1152 half-metre walkability grid, EWCG v1 |
| `minimap.webp` | rendered from the final geometry, north up |
| `camera-views.json` | the camera set, for the in-engine capture harness |
| `source/` | the build. `python3 build_westhaven.py` reproduces every artefact above byte-for-byte |
| `references/` | the concept art, the offline previews and the comparison sheets |

## Reproducing

```bash
cd source && python3 build_westhaven.py
```

Then, from the package directory:

```bash
python3 ../_toolkit/validate_gltf.py world.glb
python3 ../_toolkit/verify_runtime.py --package .
python3 ../_toolkit/capture_views.py
python3 ../_toolkit/make_comparison.py
```

The build is seeded and deterministic. Name-derived seeds go through
`noise.stable_hash()`, never the builtin `hash()`, which is salted per
interpreter run.

## The one departure from the other 576 m regions

Amberwood, Crownwater, Mirrorhold, Whitehorn Range and Amethyst Barrens all put
their arrival datum at server (174, 174). Westhaven's is at **(174, 250)**.

The concept is 40% open water. At (174, 174) only 30% of the map lies south of
the spawn, so a harbour city whose spawn is on the quay cannot have more sea
than that - the harbour, the mole and both lighthouse rocks get squeezed into a
third of the frame while the upland gets more room than the painting gives it.
Moving the datum 76 cells south makes the aerial concept map 1:1 onto the
playable square on both axes: its four edges are the map's four edges.

It costs one entry in `coordinateTransform.serverOrigin` here and one in
`ARRIVAL_TILES` in the server's `tools/generate_nymara_maps.py`. Both are data,
not code.
