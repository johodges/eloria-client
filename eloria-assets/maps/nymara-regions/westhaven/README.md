# Westhaven production map

This starter package converts the supplied `westhaven.elm` terrain, routes, water mask, and landmark placements to Godot-native GLB. The ten checkpoint subjects in `world.json` remain the visual-production brief. The invalid generated detail-board PNG was excluded and must be regenerated before visual review.

- Landmark instances: 52
- Texture kit: base color, tangent-space normal, and ORM
- Current status: terrain, traversal, material language, and landmark silhouettes; final hero geometry and set dressing remain in progress.
